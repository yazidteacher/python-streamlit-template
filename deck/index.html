🧠 Konsep 1: Variable

Dari print() ke Kotak Memori (Variable)

Perintah print() hanya menempelkan teks lalu lupa. Jika kita ingin komputer mengingat apa tugas kita, kita simpan ke dalam Variable!

# Cara Lama (Hanya Cetak Sekali & Lupa)
print("PR Matematika")

# Cara Baru (Disimpan ke Kotak Bernama)
nama_tugas = "PR Matematika"
waktu_menit = 45

# Komputer sekarang INGAT isi kotaknya!
print(nama_tugas)

📦 Analogi Kotak Bersegel Label

Nama di sebelah kiri tanda sama dengan (nama_tugas) adalah label stiker di luar kotak.

Nilai di sebelah kanan ("PR Matematika") adalah isi benda yang dimasukkan ke dalam kotak.

💡 Konsep 2: Boolean

Boolean: Saklar True & False

Komputer tidak kenal kata "mungkin". Status pengerjaan tugas hanya ada dua: True (Sudah Selesai) atau False (Belum Selesai).

# Nilai Boolean ditulis TANPA tanda kutip
# Huruf pertama WAJIB KAPITAL!

sudah_selesai = True
belum_selesai = False

print(sudah_selesai) # Output: True
⚠️ Perangkap Error Umum:
❌ "True" (Bukan boolean, ini teks biasa!)
❌ true (Error! Python sensitif huruf besar)
✔️ Penulisan Benar:
✅ is_done = True
✅ is_done = False
🔀 Konsep 3: If - Else

If - Else: Mengambil Keputusan

Komputer memeriksa kondisi: Jika bernilai True, jalankan aksi A. Jika bernilai False, jalankan aksi B!

sudah_selesai = True

if sudah_selesai:
    print("🎉 Hore! Tugas sudah selesai!")
else:
    print("⏳ Semangat, kerjakan tugasmu!")

2 Aturan Emas Python:

1. Titik Dua (:)
Wajib ada di akhir baris if dan else sebagai penanda pintu masuk.
2. Indentasi (Tab / 4 Spasi)
Baris perintah di dalam if atau else wajib digeser masuk ke kanan!

✍️ Praktik Codespaces

Cara Buka, Tulis & Edit Kode di Codespaces 💻

Ikuti 4 langkah mudah ini di layar Codespaces kamu untuk mulai menulis kode:

1

Buka File di Sebelah Kiri

Di daftar file sebelah kiri, klik file app_simple.py untuk membukanya di editor.

2

Tulis Judul & Input Teks

Ketik st.title("To-Do List Saya") dan buat variabel nama_tugas = st.text_input("Tugas:").

3

Tambah Checkbox Boolean

Ketik sudah_selesai = st.checkbox("Tandai jika sudah selesai").

4

Simpan Perubahan (Save)

Tekan Ctrl + S (atau Cmd + S di Mac) setiap kali selesai mengedit baris kode!

⚡ Eksekusi Web

Menjalankan Web App di GitHub Codespaces

Web app kita langsung berjalan di server cloud Codespaces tanpa perlu install apapun di laptop!

1. Buka Terminal & Ketik:

streamlit run app_simple.py

Lalu tekan tombol Enter pada keyboard.

2. Klik "Open in Browser":

Codespaces akan otomatis mendeteksi Port 8501 dan memunculkan pop-up di kanan bawah.

Klik tombol biru "Open in Browser" untuk melihat aplikasi web pribadimu terbuka seketika!

🌐 Deploy Publik

Deploy ke Internet (Streamlit Community Cloud) 🚀

Mau pamer aplikasi To-Do List ini ke orang tua atau teman lewat link HP? Ikuti 4 langkah ini:

1

Simpan & Push ke GitHub

Klik tab Source Control di kiri VS Code Codespaces, ketik pesan lalu klik Commit & Push.

2

Buka share.streamlit.io

Buka share.streamlit.io di browser dan Login dengan akun GitHub kamu.

3

Pilih Repositori Kamu

Klik "Create app" → pilih repo kamu, branch main, dan file app_simple.py.

4

Klik "Deploy"!

Dalam 1 menit, web app kamu resmi live dengan link publik gratis yang bisa dibuka di HP siapa pun!

🛠️ Bantuan Instan

Kalau Ada Error, Jangan Panik!

Programmer hebat bukan yang tidak pernah error, tapi yang tahu cara membaca pesan error:

🔴 IndentationError

Lupa spasi setelah if: atau else:.
👉 Solusi: Tekan tombol Tab sekali pada baris di bawah if atau else.

🟡 Web Belum Muncul di Browser?

Pop-up tertutup atau terhalang browser.
👉 Solusi: Klik tab PORTS di sebelah Terminal di bawah, lalu klik ikon bola dunia pada baris 8501!
